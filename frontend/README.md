# Ahmed Bargady - Personal Portfolio

Personal portfolio website of Ahmed Bargady, PhD Student in AI & Cybersecurity at University Mohammed VI Polytechnic (UM6P).

## About

This portfolio showcases my research work, professional experience, and projects in the intersection of Artificial Intelligence and Cybersecurity. I specialize in leveraging Large Language Models (LLMs) to enhance AI-driven Intrusion Detection Systems (IDS).

### Current Focus

- 🎓 PhD Student at UM6P, College of Computing, Benguerir (2024 – present)
- 🔬 Research: AI-driven Intrusion Detection Systems using LLMs
- 💼 Research Engineer with experience in cybersecurity and AI applications

## Tech Stack

This portfolio is built with:

- **Framework**: Next.js 15 with TypeScript
- **Styling**: Tailwind CSS 4
- **UI Components**: Radix UI primitives with custom styling
- **Animations**: Motion (Framer Motion successor)
- **Icons**: Lucide React

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
